# Results

This directory is a placeholder for pipeline outputs (trained checkpoints,
evaluation tables, XAI figures, robustness/audit CSVs, etc.).

Outputs are **not** committed to this repository — they are regenerated by
running the notebooks in `notebooks/` or the scripts in `src/` against your
own `OUTPUT_ROOT` (see the main README and `config.py`).

Expected subfolders once a run has been produced, under
`<OUTPUT_ROOT>/<RUN_NAME>/`:

```
checkpoints/        trained .keras model checkpoints
logs/                training logs, timing
outputs/             metrics, class weights, dataset splits (JSON)
revision_outputs/    segmentation audit, robustness, external validation,
                     expanded XAI statistics, multi-seed stability results
```
